# Team-Documentation-Project-
## A Guide to Non-Profit Grant Writing
This repository was formed to organize the workflow process for Documentation Project Group 1's "A Guide to Non-Profit Grant Writing." Contributors include Chloe Brown, Amy Muro, James Rowland, and Carson Wright. The folders included as of this week (September 6th-September 13th) are the Team Audience and Task Research Plan and a model for grant documentation found under the "Document Review Repository."  Important materials can be found as branches from the "main" structure. To navigate this repository, assignments occur as branches from the "main" file and are listed in order by date created as well as "issues" for general changes.
## Branch Explanations
Document-Review-Repository – contains supporting materials used for the guide and preliminary research questions

Final-Team-Project-Package – contains our handoff memo and final version of the site

Design-system-page-template– contains our design templates,  image linking rules, and accessibility checklist

Project-Status-Report – contains a project status report dated Oct 31, 2026.

Team-Audience-and-Task-Research-Plan – contains our audience and task research plan


Team-Ethics-Accessibility-Risk-Review – contains our risk and ethics review with a related revision plan
Team-Final-Revision-and-Portfolio-Case-Study-Draft – contains our project case study and list of individual member contributions

Content-audit-style-sheet-v1 – contains our content audit and style sheet

Manual-draft-v1 – contains a working draft of the guide

Project-charter-draft – contains our project charter

Usability-test – contains all materials related to our usability testing process
