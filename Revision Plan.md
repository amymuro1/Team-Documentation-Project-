# Revision Plan #
After reviewing our website through the lens of accessibility, ethics, inclusion, risk, and impact, we have developed the following revision plan. The numbered issues correlate with the numbered revisions. **For example, issue number 1's revision is revision 1.** 
## Issues ## 
1. The website guide navigation bar requires you to use the scrollbar to access the rest of the navigation tabs when using a smaller device to access the website. This could pose an issue of accessibility. 
2. In our section "Grant Writing in Action," our links are not descriptive; rather, they are just links, and there is no writing direction for the links.
3. The website relies heavily on the Common Proposal Form Grant Reference document. We only have the document linked as a download file. What if the user is using a company website that does not allow them to download direct files? This could pose an issue of inclusion.
4. The _Grant Writing in Action_ tab has a small "drop-down" menu that directs users to sections of the tab, though that small menu is not shown on a mobile device. This can be an issue of mobile accessibility. 

## Revisions Planned ## 
1. Using our coding platform, we will ensure we add the navigation bar to the left so that it can also be fully accessible on a mobile device if needed. 
2. We will change the links to descriptive links instead. For example, the link can be named "Click here to access the Bank of America's Grant Writing Guide"
3. Aside from adding the _Common Proposal Form Grant Reference_ document as a link, we can either embed the common proposal form or include images in a separate tab or the same tab under a heading that mentions "problems with accessing the link?"
4. We can use our code to ensure that on mobile devices the navigation bar presents the same components as the navigation bar on the website.
